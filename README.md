# 🏁 Need for Speed — Projeto HTML

Projeto desenvolvido como atividade prática durante as aulas de tecnologia/desenvolvimento no **SENAI**. A página apresenta uma temática inspirada no universo de corridas e no jogo **Need for Speed Underground II**, utilizando HTML para estruturar o conteúdo.

## 🎯 Objetivo

Praticar os fundamentos de HTML por meio da criação de uma página temática, trabalhando elementos de texto, imagens, listas, tabelas, links e organização de conteúdo.

## 🖥️ Sobre o projeto

A página contém:

- Uma imagem de capa relacionada ao tema;
- Título principal e identidade visual inspirada em Need for Speed;
- Link externo para acessar uma versão online do jogo;
- Relação de carros apresentados com imagens;
- Tabela com pistas, número de voltas, comprimento e localização;
- Bandeiras dos países correspondentes;
- Lista de classificação dos participantes de uma corrida;
- Link para assistir a uma corrida em vídeo.

## 🧰 Tecnologias utilizadas

- **HTML5** — estruturação e organização do conteúdo;
- **Imagens** — recursos visuais locais utilizados na página;
- **Links externos** — acesso a conteúdo relacionado ao tema.

O estilo visual foi aplicado diretamente no HTML, por meio de atributos e CSS incorporado no próprio documento. O projeto não utiliza framework ou biblioteca JavaScript.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado em ZIP.
3. Abra a pasta do projeto.
4. Dê dois cliques no arquivo `site.html` ou abra-o em um navegador (Google Chrome, Microsoft Edge, Firefox etc.).

Não é necessário instalar dependências ou executar um servidor para visualizar esta página.

## 📝 Observações

Este é um projeto educacional, desenvolvido para praticar os fundamentos de HTML. Os dados apresentados sobre pistas, carros e classificação fazem parte do conteúdo demonstrativo da página e não representam informações oficiais ou atualizadas do jogo.
